# Milestone 1 — Working local dictation

## Objective
Create a local Windows dictation tool that works end-to-end.

## Required features
- configurable hotkey
- microphone recording
- local transcription
- basic punctuation cleanup
- clipboard paste into active app

## Definition of done
- user can trigger dictation from any app
- spoken text becomes editable text in the active field
- latency is acceptable for personal daily use
- failure states are visible and understandable

## Out of scope
- wake word
- full command mode
- advanced rewriting
- polished UI
