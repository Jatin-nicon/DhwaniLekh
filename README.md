# Wispr Flow Clone

This folder is for planning and building a personal system-wide dictation tool inspired by the experience of Wispr Flow.

## Goal

Build a desktop voice-to-text assistant that can:
- capture speech quickly
- transcribe it accurately
- clean and format text
- paste into the active app
- later support rewrite modes and voice commands

## Current stage

Planning only. No product code yet.

## Folder map

- `docs/` — product and roadmap docs
- `architecture/` — technical design notes
- `milestones/` — execution plan by version

## Suggested first build target

Version 1:
- press a hotkey
- record speech
- transcribe locally
- lightly clean the text
- paste into the active text field
