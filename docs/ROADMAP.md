# Roadmap

## Phase 1 — MVP
Build the smallest useful version:
1. global hotkey
2. audio capture
3. speech-to-text
4. basic cleanup
5. auto-paste

## Phase 2 — Text quality
Add:
- punctuation
- capitalization
- paragraph handling
- spoken formatting commands

## Phase 3 — Rewrite modes
Add optional modes such as:
- clean
- professional
- concise
- email
- message

## Phase 4 — Command mode
Add desktop control actions like:
- open app
- search web
- simple shortcuts
- send / submit actions

## Phase 5 — Product polish
Add:
- tray icon
- settings
- mic selection
- hotkey selection
- transcription history
- latency improvements

## Phase 6 — Wake word / continuous mode
Only after hotkey mode is stable and reliable.
