# Security & Privacy Policy

## Our Privacy Pledge

**DhwaniLekh is 100% local-first and offline by default.**
- **No telemetry or analytics tracking**: We do not collect or log personal user metrics.
- **Zero cloud audio upload**: All speech-to-text processing occurs strictly on your local machine using local Whisper neural models.
- **No keystroke logging**: Keyboard hooks are exclusively used to capture the configured dictation hotkey.

---

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy loophole in DhwaniLekh, please do **NOT** open a public issue.

Instead, please report it privately:

1. **Email maintainer**: Send an email with full details to **jatinkumar79911@gmail.com**.
2. **Include details**:
   - Description of the potential vulnerability
   - Steps or proof-of-concept script to reproduce
   - Potential impact
3. **Response timeline**: We will acknowledge receipt of your report within 48 hours and work with you on a resolution prior to any public disclosure.
